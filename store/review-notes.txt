hYYa Digital Footprint Check is a free privacy-education app. It reads the same device information any iOS app can read and shows it ONLY to the person holding the device, so they can see their own "fingerprint" and reduce it. Nothing is collected, stored off the device or transmitted: no account, no server, no analytics, no third-party SDK. App Privacy: "Data Not Collected".

No login is required. To review:
1. Tap "Start with check 1". Results appear in about 3 seconds, with one privacy score.
2. Footprint lists what can be fixed. "Fix them with me" opens Settings step by step; it changes no setting.
3. Each permission category ("Seen once you allow it") asks for that permission only when the user taps "Show me", then shows counts and summaries (never contacts' names, numbers or event titles).
4. "Sensitive apps": all categories are on by default; the user taps Check.
5. "Tracker": the user opens the App Privacy Report file they saved from Settings with the file picker. It is read on the device only; never stored or sent.

CallKit (5, China): not included or linked in any territory.

VPN: the app has NO VPN functionality, no Network Extension entitlement and makes no network connections. One finding shows whether a VPN is on (CFNetworkCopySystemProxySettings), and the user-initiated "Sensitive apps" check can test for four VPN apps (URL schemes psiphon, onionhttp, protonvpn, nordvpn). Shown only to the device owner, never sent.

Fingerprinting (5.1.2): the app fingerprints no one. Values are shown to the owner and never leave the device. Scan history keeps only salted one-way hashes, the score and ids of notable findings, and is excluded from backups.

LSApplicationQueriesSchemes (25): used only for the user-initiated "Sensitive apps" check. Results are hidden until tapped, cleared when the app leaves the screen and never sent; only the count stays on the device.

Required Reason APIs: boot time, disk space, keyboards, file timestamps and user defaults are read only to display them to the user; the privacy manifest declares them.

Keychain: only the app's own install dates (a reinstall demonstration) and the widget's score and last-check date, ThisDeviceOnly, never synced. Motion sensors also drive a subtle tilt on the mascot; nothing is recorded. StoreKit and MusicKit show the App Store country, original download date and Apple Music status to the user. Apple frameworks only.

Check-up steps are instructions only: the app reads none of those settings, detects no malware and reads no passwords. Optional local re-scan reminder: no server, no push. The widget shows only the score and last-check time.

Since 1.1.3:

- Sensitive Content Analysis entitlement: used only to read SCSensitivityAnalyzer.analysisPolicy, to show the user that any app can tell whether Communication Safety or Sensitive Content Warning is on. No images or videos are analysed; the reading is shown on screen only and never scored.
- New Check-up steps (Safari protection, Journaling Suggestions, Analytics and Apple Advertising, Advanced Data Protection, RCS Messaging): instructions only.
- A one-time in-app notice that three of the developer's other apps are on sale until 31 December. It is built into the app (nothing is fetched), opens their App Store pages, and is never a notification.
