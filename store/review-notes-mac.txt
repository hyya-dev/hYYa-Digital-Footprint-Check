hYYa Digital Footprint Check for Mac is a free privacy-education app. It reads the same information any sandboxed Mac App Store app can read and shows it ONLY to the person using the Mac, so they can see their own "fingerprint" and reduce it. Nothing is collected, stored off the device or transmitted: there is no account, no server, no analytics, no third-party SDK, and the app has no network entitlement. The App Privacy label is "Data Not Collected".

No login is required. To review:
1. Click "Start with check 1". Results appear in a few seconds.
2. Footprint lists what can be fixed ("See everything apps can read" shows the rest). Click any item to see what it reveals and how to fix it. Where a fix exists, "Open in System Settings" opens the matching System Settings page.
3. Each permission category ("Seen once you allow it") asks for that permission only when the user clicks "Show me", and shows counts and summaries only.
4. "Sensitive apps": all categories are on by default (any can be turned off); the user clicks Check. Results are hidden until clicked, cleared when the app goes to the background, and never sent. Only the count found stays on the device, never which apps.
5. "Check-up" walks through the Privacy & Security pages of System Settings.
6. Settings opens in its own window (hYYa Digital Footprint Check menu › Settings, or ⌘,).

About device identifiers and personal information (5.1.1, 5.1.2): the app displays the Mac's serial number, hardware UUID, the user's full name, computer name, network hardware addresses, running apps and installed apps. It does this ONLY to show the user, on screen, that any app can read these without asking. None of these values are stored, logged, hashed for tracking or sent anywhere. Scan history keeps only salted one-way hashes, used to show "what changed since your last scan", and is excluded from backups.

About the installed-app check: it reads the app names in /Applications and /System/Applications (readable by any sandboxed app) and, for a few apps, whether a URL scheme has a handler. It is user-initiated, and only the count found stays on the device, never which apps.

About entitlements: camera (to list camera names only; no capture), Bluetooth, location, contacts, calendars/reminders and photos are each requested only when the user clicks "Show me" for that category. The app uses only Apple frameworks.

The app has no CallKit and no pricing references in its screenshots.

Also in the app:
- Tracker: lists the System Settings panes that show which apps can record the screen, use accessibility, monitor input or read all files, each opened with an x-apple.systempreferences link. The app reads none of these itself.
- Re-scan reminder: optional local notification (weekly or monthly), asked for only when chosen. No server, no push.
- "Fix them with me": steps through fixable findings and opens System Settings; the app never changes a setting itself.

Widget: only the score and last-check time, from a device-only keychain item; no network, no finding or app name.
Check-up steps are instructions only: the app reads none of those settings, detects no malware and reads no passwords.

New in 1.1.3:
- Declared Age Range: only where Apple reports that an age-assurance law applies, the app shows Apple's age-range sheet after install or update, then at most yearly. Nothing is gated on it; it is never stored, logged or sent.
- Sensitive Content Analysis entitlement: only to read SCSensitivityAnalyzer.analysisPolicy and show the user that apps can tell whether Communication Safety or Sensitive Content Warning is on. No content is analysed; never scored.
- New Check-up steps (Safari protection, Analytics and Apple Advertising, Advanced Data Protection): instructions only.
- A one-time in-app notice that the developer's other apps are on sale until 31 December. It is built into the app (nothing is fetched), opens their App Store pages, and is never a notification.
